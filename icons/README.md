# Extension Icons

## Generating Icons

To generate the required icon files for the Chrome extension:

1. Open `generate-icons.html` in your web browser
2. Click each download button to save the icons:
   - icon16.png (16x16 pixels)
   - icon48.png (48x48 pixels)
   - icon128.png (128x128 pixels)
3. Save all downloaded files to this `icons/` directory

## Icon Sizes

- **16x16**: Used in the browser toolbar
- **48x48**: Used in the Extensions management page
- **128x128**: Used in the Chrome Web Store and during installation

## Alternative: Using SVG

You can also convert the `icon.svg` file to PNG format using any image editing tool or online converter:
- Export to 16x16, 48x48, and 128x128 PNG files
- Ensure the images are crisp and not blurry

## Quick Setup

If you want to quickly test the extension without proper icons, you can use placeholder images. However, for a production release, proper icons are recommended.
